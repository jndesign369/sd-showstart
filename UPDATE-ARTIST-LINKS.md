# Update your existing GitHub repository

For the current **v0.3.0** release, follow
[UPDATE-v0.3.0.md](UPDATE-v0.3.0.md). The downloadable archive is
`San Diego Shows starter kit-v0.3.0.zip`; check the `VERSION` file inside.

This release adds files and changes the existing workflow, so the older
presentation-only upload instructions are no longer sufficient. Keep your
existing repository, preserve fresher show data and optional corrections, and
use the current update checklist rather than uploading the ZIP itself.

The assistant has not changed your GitHub repository remotely. Once the code,
artist cache, and workflow are uploaded, the workflow can rebuild your own
snapshot with the new artist-link policy.
